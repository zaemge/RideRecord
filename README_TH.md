# RideRecord — Free PWA

RideRecord เวอร์ชันนี้สร้างให้ใช้งานแบบ **Mobile-first PWA** และเน้นใช้บริการฟรี/โอเพนซอร์ส โดยไม่ต้องใช้ OpenAI API หรือ Google Maps API

## ฟังก์ชันที่มีแล้ว

- เพิ่ม/เลือก/ลบรถหลายคัน
- บันทึก ราคาน้ำมัน, ลิตรที่เติม, เลขไมล์, วันที่เติม
- คำนวณจากรอบเติมน้ำมัน:
  - อัตราสิ้นเปลือง (km/l)
  - ค่าใช้จ่ายต่อ km
  - ปริมาณน้ำมันที่เติม
  - ระยะทางที่วิ่งได้โดยประมาณ
- สรุปรายเดือนและกราฟ 6 เดือน
- Trip Planner ใช้ GPS ของมือถือ
- แผนที่ OpenStreetMap ผ่าน Leaflet
- เส้นทางรถยนต์ผ่าน OSRM
- ค้นหาสถานที่ผ่าน Nominatim แบบกดค้นหาเท่านั้น (ไม่มี autocomplete)
- ค้นหาปั๊มน้ำมันใกล้เส้นทางผ่าน Overpass API พร้อม cache และ rate limit
- ตั้งระยะเตือนเติมน้ำมัน
- บันทึกทริป
- Export / Import ข้อมูลเป็น JSON
- PWA / Add to Home Screen
- เก็บข้อมูลใน localStorage ของเครื่อง ไม่ต้องมีฐานข้อมูลเสียเงิน

## สูตรการคำนวณ

เมื่อมีรายการเติมก่อนหน้า:

- ระยะทางรอบนี้ = เลขไมล์ปัจจุบัน - เลขไมล์ครั้งก่อน
- อัตราสิ้นเปลือง = ระยะทางรอบนี้ / ปริมาณน้ำมันที่เติมครั้งนี้
- ค่าใช้จ่ายรอบนี้ = ราคาน้ำมันต่อลิตร × ปริมาณลิตร
- ค่าใช้จ่ายต่อ km = ค่าใช้จ่ายรอบนี้ / ระยะทางรอบนี้
- ระยะทางที่วิ่งได้โดยประมาณ = km/l × ปริมาณน้ำมันที่เติม

รายการเติมครั้งแรกของรถแต่ละคันจะเป็น “ฐานเลขไมล์” ดังนั้น km/l จะเริ่มคำนวณได้ตั้งแต่รายการถัดไป

## เปิดทดสอบในเครื่อง

ถ้ามี Node.js:

```bash
npm install
npm run dev
```

หรือใช้ static web server ใดก็ได้ โดยโฟลเดอร์เว็บไซต์คือ `public/`

## Deploy ฟรีบน Cloudflare

โปรเจกต์มี `wrangler.jsonc` เตรียมไว้แล้ว:

```bash
npm install
npx wrangler login
npm run deploy
```

หลัง Deploy จะได้ HTTPS ซึ่งจำเป็นสำหรับ GPS และการติดตั้ง PWA บนมือถือ

## ติดตั้งบน iPhone

1. เปิด URL ที่ Deploy แล้วด้วย Safari
2. กด Share
3. เลือก Add to Home Screen
4. เปิด RideRecord จากไอคอนบนหน้าจอ Home

## เรื่อง “ใช้ฟรี” ของแผนที่

ตัวแอปไม่มี API key และไม่มีค่าบริการรายเดือน แต่บริการสาธารณะของ OpenStreetMap/OSRM/Nominatim/Overpass เป็นทรัพยากรชุมชนและมีข้อจำกัดการใช้งาน ไม่รับประกัน uptime/SLA และไม่เหมาะกับการใช้งานปริมาณมากเชิงพาณิชย์

- Tile แผนที่ใช้เฉพาะตอนผู้ใช้เปิดดู และแสดง attribution
- Service Worker ของ RideRecord **ไม่ cache หรือ prefetch tile แผนที่**
- Nominatim ค้นหาเมื่อผู้ใช้กดค้นหาเท่านั้น และมี cache ในเครื่อง
- Overpass ค้นหาปั๊มตามเส้นทางแบบจำกัดความถี่และ cache ผลลัพธ์
- ถ้าภายหลังมีผู้ใช้จำนวนมาก ควรเปลี่ยน endpoint เป็นบริการที่รองรับ production หรือ self-host

## ข้อจำกัดของเวอร์ชันฟรีนี้

- ข้อมูลยัง sync ข้ามเครื่องอัตโนมัติไม่ได้ เพราะเก็บไว้ในเครื่องเท่านั้น
- GPS ต้องได้รับ permission จากผู้ใช้
- แผนที่/เส้นทาง/ค้นหาปั๊มต้องมีอินเทอร์เน็ต
- บริการ routing/geocoding สาธารณะอาจช้าหรือปิดชั่วคราวได้
